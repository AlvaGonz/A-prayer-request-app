# ui-ux-pro-max-skill (Local Alias)

**Purpose:** Provide Multi-platform UI/UX design intelligence of professional level. 
**When to Use:** Whenever you need UI styles, color palettes, font pairings, chart types, or want a full design system generated for a feature or page.

**Global Installation Path:** `~/.gemini/antigravity/skills/ui-ux-pro-max`
**Documentation:** [Official README](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill)

> **Important:** This is merely an alias to expose the capability to this workspace. Do not generate UI code blindly; use this skill to fetch design systems (Master rules and overrides) tailored by the advanced rule engine in the global directory.

## Expected Artifacts
- **design-system/MASTER.md** - Global Source of Truth (colors, typography, spacing, components)
- **design-system/pages/[page].md** - Page-specific overrides

"Usar ui-ux-pro-max-skill para auditar esta pantalla y proponer mejoras."
